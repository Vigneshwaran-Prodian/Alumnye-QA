Scoring Methodology

How a golf fixture's handicap is calculated, how each of the three formats scores a round, and how results roll up into tournament standings.

Net Stroke Play Net Stableford Four-Ball Match Play Handicap locked at start
01

Handicap & stroke allocation

Applies identically underneath all three formats. Handicap is entered once and locked when the fixture starts — the app stores per-hole gross scores and par so a future Dynamic Handicap System can be layered on without losing history.

// applied once, at Play the Fixture
playingHandicap(base, allowancePct=75, holes=18) = round( round(base × allowancePct / 100) )
// 9-hole matches halve this value before rounding

// applied per hole, per player
strokesOnHole(ch, strokeIndex) = floor(ch / 18) + (strokeIndex ≤ ch % 18 ? 1 : 0)
net(gross, ch, strokeIndex) = gross − strokesOnHole(ch, strokeIndex)

02

Three scoring formats, one hole, three outcomes

All three read the same gross scores off the same hole — only the scoring engine branch differs. Par 4, Stroke Index 3, all four players receive a stroke.

Format A

Net Stroke Play

  • Team total = sum of the side's net score per hole; in 2v2 the side counts only its best net ball per hole.
  • Lowest total net across the round wins. Win = 1 pt · tie = ½ each · loss = 0.

Format B

Net Stableford

  • Per hole, per player: net eagle = 4 · net birdie = 3 · net par = 2 · net bogey = 1 · net double-bogey-or-worse (or pickup) = 0.
  • Pairing score per hole = sum of both players' points (1v1: the individual's points alone).
  • Match margin = pair A total − pair B total. The signed margin is added to / subtracted from the team leaderboard.

Format C

Four-Ball Match Play

  • 2v2 only. Per hole, best net ball of each pair is compared → hole is won or halved.
  • Match decided on holes won across the round. Win = 2 pts · draw = 1 each · loss = 0.
  • A hole a side doesn't complete is marked X; the anchor then posts the manual result in the MVP (a dedicated X flow is Phase 2).

04

From fixture result to tournament standings

Every completed fixture — regardless of which of the three formats it used — contributes to the same standings table.

standings(tournament) = Σ points_team_x over DONE fixtures
// Net Stroke Play & Four-Ball Match Play contribute fixed points (1/0.5/0 or 2/1/0)
// Net Stableford contributes a signed margin instead of a fixed point
Highest total leads · ranking shown as Win / Tie / Loss per team
